资金调拨流程测试

按步骤插入模拟银行流水，并携带 Cookie 调用 BossMgr 资金调拨处理接口

第一步：新增一条流水 未执行

执行配置中心里的 Oracle 连接，向 PAYMENTDB.T_CEBANK_QUERY 插入一条金额为 100002 的模拟流水。

查看执行 SQL
INSERT INTO PAYMENTDB.T_CEBANK_QUERY (...字段略...) VALUES ( (SELECT NVL(MAX(CE_ID), 0) + 1 FROM PAYMENTDB.T_CEBANK_QUERY), TO_CHAR(SYSTIMESTAMP, 'YYYYMMDDHH24MISSFF3') || TRUNC(DBMS_RANDOM.VALUE(100, 999)), '人民币', 100002, '贷', ..., 'Mock银行', '6213350207668213010', '集团内部公司A', '600000' );
第二步：调用调拨接口 未执行

输入登录态 Cookie（或点击下方按钮自动获取），POST 调用配置中心中的资金调拨接口地址。

短时间批量调用同一个调拨接口，用于观察是否出现重复调拨。建议先新增一条流水，再批量调用，最后查看结果。

第三步：查看结果 未执行

使用第一步返回的 DATE_NET_SERIAL 查询调拨订单、银行订单、审核记录和账户明细流水；多条可用英文逗号分隔。

查看执行 SQL
SELECT t.ORDER_NO, t.CE_ID, t.ORDER_STATUS, t.RECHARGE_STATUS, t.TRANSFER_TYPE, t.AMOUNT, b.ID AS BANK_ORDER_PK, b.ORDER_ID, b.TRANS_ORDER_ID, b.BANK_ORDER_ID, b.ACC_TYPE, b.STATE AS BANK_ORDER_STATE, b.AMT, b.TRANS_CODE, b.TRANS_MSG, b.QUERY_CODE, b.QUERY_MSG, b.CREATE_TIME, b.UPDATE_TIME FROM T_TRANSFER_ORDER t LEFT JOIN T_BANK_ORDER b ON b.ORDER_ID = t.ORDER_NO WHERE t.CE_ID IN (SELECT CE_ID FROM T_CEBANK_QUERY WHERE DATE_NET_SERIAL IN (':date_net_serial1', ':date_net_serial2')); SELECT ID, ORDER_ID, DATE_NET_SERIAL, ACCOUNT_ID, ACC_TYPE, CHANGE_AMT, FEE, STATE, AUDIT_STATE, MEMO, CREATE_TIME, UPDATE_TIME FROM T_ACC_REVIEW_RECORD WHERE DATE_NET_SERIAL IN (SELECT DATE_NET_SERIAL FROM T_CEBANK_QUERY WHERE DATE_NET_SERIAL IN (':date_net_serial1', ':date_net_serial2')); SELECT * FROM T_ACC_DETAIL_TRANS WHERE ORDER_ID IN (SELECT ORDER_ID FROM T_ACC_REVIEW_RECORD WHERE DATE_NET_SERIAL IN (':date_net_serial1', ':date_net_serial2'));
