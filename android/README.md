# AI 观鸟 Android

原生 Android 外壳 + 本地 WebView 界面，仅包含 DeepSeek AI 观鸟问答。涉及近期、地点、鸟种和记录的问题会强制调用内置查询工具，从观鸟记录中心获取真实公开记录后再回答。

- 首次启动要求输入 DeepSeek API Key
- API Key 使用 AndroidKeyStore（AES/GCM）加密并仅保存在设备本机
- 最近 10 组问答保存在设备本机，超出后自动删除最早一组
- 支持观鸟记录中心 RSA 签名请求、AES 数据解密和访问验证码
- 查询前自动纠正省市参数，普通城市被误填为省份时会改用城市查询
- 每次真实查询会显示查询日期、区域及记录条数，便于确认数据来源
- 使用翠鸟启动图标和翠鸟主题聊天界面
- 可清空对话或更换 API Key
- 版本号遵循语义化版本格式，每次功能或界面修改递增补丁版本号（如 `4.0.0` → `4.0.1`）。

构建：

```bash
gradle assembleDebug
```
